# cargo-dep-graph

Инструмент визуализации графа зависимостей для
менеджера пакетов **Rust (Cargo)**.

> Практическая работа по дисциплине
> «Конфигурационное управление» (Вариант №4).
> Студент: ИКБО-42-25, РТУ МИРЭА.

## Описание

Приложение анализирует зависимости Rust-пакета, строит
граф (итеративный DFS), фильтрует по подстроке и
визуализирует результат через Graphviz (PNG).

## Параметры конфигурации (CSV)

| Поле              | Описание                        |
|-------------------|---------------------------------|
| package_name      | Имя пакета                      |
| source            | URL или путь к тестовому файлу  |
| test_mode         | on/off                          |
| output_file       | Имя PNG-файла                   |
| filter_substring  | Подстрока фильтрации            |
